# smart-retro-hid-protocol

USB-MIDIを利用した汎用HID制御通信プロトコルライブラリ。Dart（Flutter向け）とC/C++（マイコン向け）の実装を提供。

## 概要

スマートフォンとマイコン間のUSB-MIDI通信を抽象化し、キーボード・マウス・ジョイスティックなどのHIDデバイス制御メッセージを送受信するためのプロトコルを定義する。
